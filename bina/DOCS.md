# Bina

1. Install and open the configuration tab.
2. Paste your Anthropic API key (console.anthropic.com).
3. Set the house name, owner name and language.
4. Optional: list protected entities (locks, alarm) that always require confirmation.
5. Start. Open Bina from the sidebar, or from your phone through your Home Assistant remote URL. Add to Home Screen.

Bina uses the entities exposed to Assist (Settings > Voice assistants > Expose) plus anything in the areas you defined.
